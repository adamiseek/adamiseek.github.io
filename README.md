# adamiseek — portfolio

Personal portfolio and homepage of Adam, a security-minded full-stack developer from Slovakia.

## Live site

- https://adamiseek.pages.dev

## Stack

- Plain HTML, CSS, JavaScript
- No frameworks, no build step
- Canvas-based network background
- Responsive from mobile to desktop

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000

## Sections

- About
- Skills & languages (filterable)
- Projects
- Certifications
- Contact

Built by hand, hardened on purpose.
